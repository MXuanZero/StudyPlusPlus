维护说明

更新进度时，只需修改本文件 <script> 中的 TASKS 数组：

  • 把任务的 status 改为 "pending"、"in_progress"、"completed" 或 "blocked"。
  • 把子项的 done 改为 true 或 false；页面会自动计算总进度和任务进度。
  • 每次更新后，同时在 UPDATE_LOG 中追加一行日期与说明。

所有开发必须遵循 docs/04_开发任务拆分与验收.md 中的 Definition of Done。
