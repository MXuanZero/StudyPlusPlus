# StudyPlusPlus 新机器初始化与启动指南

> 版本：v1.0  
> 适用项目：StudyPlusPlus  
> 目标：在一台全新的机器上，从零安装依赖、初始化数据、启动网站，并完成基本验证。

---

## 1. 适用范围

本指南覆盖：

1. 新机器首次获取项目；
2. 安装 Python 后端依赖；
3. 安装 Node / npm 前端依赖；
4. 构建前端；
5. 初始化本地 SQLite 数据库；
6. 配置大模型（可选）；
7. 生产模式启动；
8. 开发模式启动；
9. 基本验证与常见问题排查。

项目已经在以下环境验证过：

| --- | --- |
| Python | 3.14.4 |
| FastAPI | 0.121.2 |
| Uvicorn | 0.40.0 |
| SciPy | 1.18.1 |
| NumPy | 2.5.3 |
| Node.js | 24.21.0 |
| npm | 11.19.0 |
| 操作系统 | Linux（桌面环境） |

## 2. 环境要求

### 2.1 操作系统

推荐：

- Linux（当前主要开发和验证环境）
- macOS

Windows 用户建议使用：

- WSL2（推荐），或
- Git Bash for Windows

因为项目根目录的 `start.sh` 是 Bash 脚本。

### 2.2 必须安装的软件

| 软件 | 最低建议 | 检查命令 |
| --- | --- | --- |
| Python | 3.11+，推荐 3.14 | `python3 --version` |
| pip | 随 Python 安装 | `python3 -m pip --version` |
| venv | Python 自带 | `python3 -m venv --help` |
| Node.js | 18+，推荐 20/22/24 | `node --version` |
| npm | 9+ | `npm --version` |
| Git（可选） | 最新版 | `git --version` |

### 2.3 网络

首次安装需要网络，用于：

- 下载 Python 依赖；
- 下载 npm 依赖；
- 安装前端构建工具。

安装完成后，网站本身可以在本地离线运行；只有调用真实大模型时才需要网络。

## 4. 一键初始化并启动（推荐）

在项目根目录执行：

```bash
./start.sh
```

脚本会自动完成：

1. 检查 `.venv`，不存在则创建；
2. 检查后端依赖，缺失则执行 `pip install -r requirements.txt`；
3. 检查 `frontend/node_modules`，缺失则执行 `npm install`；
4. 把 npm 缓存设置到项目内 `.npm-cache`，避免 HOME 只读导致的 `EROFS`；
5. 生产模式下按需执行 `npm run build`；
6. 启动 FastAPI，并托管 `frontend/dist`；
7. 初始化或打开 SQLite 数据库。

启动后访问：

```text
http://127.0.0.1:8000
```

健康检查：

```text
http://127.0.0.1:8000/api/v1/health
```

### 4.1 一键启动参数

```bash
./start.sh                  # 生产模式，默认 127.0.0.1:8000
./start.sh --dev            # 开发模式：FastAPI reload + Vite dev server
./start.sh --no-build       # 生产模式，跳过前端构建
./start.sh --port 9000      # 指定后端端口
./start.sh --host 0.0.0.0   # 监听所有网卡
./start.sh --help           # 查看帮助
```

### 4.2 常用环境变量

```bash
HOST=127.0.0.1
PORT=8000
FRONTEND_PORT=5173
NPM_CONFIG_CACHE=/path/to/.npm-cache
```

示例：

```bash
PORT=9000 ./start.sh
```

开发模式示例：

```bash
FRONTEND_PORT=5180 ./start.sh --dev
```

### 4.3 生产模式与开发模式的区别

| 模式 | 命令 | 前端 | 后端 | 适合场景 |
| --- | --- | --- | --- | --- |
| 生产 | `./start.sh` | 构建后的 `frontend/dist` | 单端口 8000 | 日常学习使用 |
| 开发 | `./start.sh --dev` | Vite dev server 5173 | FastAPI reload 8000 | 修改代码 |

开发模式会启动两个服务：

```text
前端：http://127.0.0.1:5173
后端：http://127.0.0.1:8000
```

停止方式：

```text
按 Ctrl+C
```

## 5. 手动初始化（逐步执行）

如果你不想用一键脚本，可以手动执行。

### 5.1 创建 Python 虚拟环境

在项目根目录执行：

```bash
python3 -m venv .venv
```

升级 pip：

```bash
.venv/bin/python -m pip install --upgrade pip
```

安装依赖：

```bash
.venv/bin/pip install -r requirements.txt
```

验证：

```bash
.venv/bin/python -c "import fastapi, numpy, scipy, uvicorn; print('Python deps OK')"
```

Windows（PowerShell）对应路径：

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 5.2 安装前端依赖

```bash
cd frontend
npm_config_cache="$PWD/../.npm-cache" npm install --no-audit --no-fund
```

### 5.3 构建前端

```bash
npm run build
cd ..
```

验证生成：

```bash
ls frontend/dist/index.html
```

### 5.4 启动生产模式后端

```bash
cd backend
STUDY_DATA_DIR="$PWD/../data" ../.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
```

然后访问：

```text
http://127.0.0.1:8000
```

### 5.5 启动开发模式

后端：

```bash
cd backend
STUDY_DATA_DIR="$PWD/../data" ../.venv/bin/uvicorn app.main:app --reload --port 8000
```

前端（新终端）：

```bash
cd frontend
npm run dev
```

访问：

```text
http://127.0.0.1:5173
```

## 6. 大模型初始化配置（可选）

### 6.1 不配置 Key 的情况

**不配置任何 Key，网站也能正常运行。**

此时 AI 助教自动进入 Mock 模式，会返回内置占位回复；课程阅读、可视化、进度、笔记都不受影响。

### 6.2 方式一：通过设置页配置（推荐）

1. 启动网站；
2. 打开首页，进入「模型设置」；
3. 选择供应商：
   - DeepSeek（默认）
   - OpenAI
   - Ollama
   - 自定义 OpenAI 兼容接口
4. 填写：
   - Base URL
   - 模型名
   - API Key
   - temperature
   - max_tokens
5. 点击「保存设置」；
6. 点击「测试连接」。

配置保存在后端 SQLite：

```text
data/studyplusplus.db
```

API Key 只保存在服务端数据库，不会写入前端 localStorage。

### 6.3 方式二：通过环境变量配置

```bash
export LLM_API_KEY="你的 API Key"
./start.sh
```

优先级：

```text
数据库设置 > 环境变量 LLM_API_KEY > Mock 模式
```

### 6.4 自定义系统提示词

设置页中可以直接编辑系统提示词：

- 保存后立即对新消息和已有会话生效；
- 可点击「恢复默认提示词」恢复内置版本；
- 系统学习上下文仍会自动追加。

### 7.1 数据库位置

首次启动时自动创建：

```text

```

其中保存：

- 学习进度
- 笔记
- 聊天会话与消息
- LLM 配置
- 系统提示词

### 7.2 备份

停止服务后直接复制：

```bash
cp data/studyplusplus.db data/studyplusplus.backup.db
```

### 7.3 恢复

```bash
cp data/studyplusplus.backup.db data/studyplusplus.db
```

### 7.4 重置全部学习数据

> 警告：以下操作会删除进度、笔记、聊天历史和设置，请先备份。

```bash
rm -f data/studyplusplus.db
./start.sh
```

### 7.5 Git 忽略说明

以下目录/文件不会提交到 Git：

```text

frontend/dist/
.npm-cache/
data/
.env
*.db
```

## 9. 常见问题

### 9.1 `./start.sh: Permission denied`

```bash
chmod +x start.sh
```

### 9.2 提示找不到 Python / venv

安装 Python 3 和 venv：

Ubuntu / Debian：

```bash
sudo apt update
sudo apt install python3 python3-venv python3-pip
```

### 9.3 提示找不到 Node / npm

安装 Node.js 18+（推荐 20/22/24），然后重新执行：

```bash
node --version
npm --version
./start.sh
```

### 9.4 npm 报 `EROFS`

这是 npm 默认缓存目录不可写导致的。一键脚本已经自动使用：

```text
项目根目录/.npm-cache
```

手动安装时请使用：

```bash
npm_config_cache="$PWD/../.npm-cache" npm install
```

### 9.5 端口被占用

指定其他端口：

```bash
./start.sh --port 9000
```

开发模式指定 Vite 端口：

```bash
FRONTEND_PORT=5180 ./start.sh --dev
```

### 9.6 页面打不开或白屏

依次尝试：

1. 强制刷新浏览器：`Ctrl + Shift + R`；
2. 确认后端进程还在运行；
3. 重启服务：

```bash
# 在原终端按 Ctrl+C
./start.sh
```

4. 如果刚更新过代码，重新构建前端：

```bash
cd frontend
npm_config_cache="$PWD/../.npm-cache" npm run build
cd ..
./start.sh
```

### 9.7 修改代码后没有生效

- 生产模式：重新执行 `npm run build`，然后刷新浏览器；
- 开发模式：Vite 会热更新，后端 `--reload` 会自动重启；
- 如果后端不是 `--reload` 启动的，需要手动重启。

### 9.8 想换机器继续使用

复制：

```text
整个项目目录
data/studyplusplus.db
```

在新机器上安装依赖并启动即可保留进度、笔记和会话。

> `data/` 默认被 Git 忽略，不会自动同步，需要手动复制数据库。

- [ ] `.venv` 创建成功，后端依赖安装成功；

- [ ] `./start.sh` 能启动服务；

- [ ] 首页、第 3/4/5/6 章页面可以打开；
- [ ] 公式能够正常渲染；
- [ ] AI 助教在未配置 Key 时以 Mock 模式工作；
- [ ] 设置页可以配置大模型；
- [ ] `data/studyplusplus.db` 自动创建；
- [ ] 刷新页面或重启服务后，进度、笔记、会话仍然存在。
