> 版本：v0.1

---

## 1. 背景与目标

### 1.1 背景
用户希望学习控制理论，参考目录来自：
- 《控制之美（卷 1）：控制理论从传递函数到状态空间》
- 《控制之美（卷 2）：最优化控制 MPC 与卡尔曼滤波器》

用户的数学基础和物理基础较薄弱，直接阅读公式推导困难，希望通过**可视化、可交互、可对话**的方式学习。

### 1.2 产品目标
1. 把抽象的控制理论概念变成“看得见、拖得动、可对比”的交互式图表。
2. 在网站任意页面都能随时与大模型对话，且对话知道“用户正在学什么”。
3. 将大量计算（微分方程求解、响应曲线、性能指标、扫描分析）放到 Python 后端。
4. 首期用**二阶系统时域响应分析**验证完整学习闭环，再逐步扩展到全书。

### 1.3 非目标（MVP 不做）
- 不做移动端适配。
- 不做多用户、登录、注册、权限系统。
- 不复制或 OCR 参考书原文；只按目录结构自编课程内容。
- 不接入教科书全文检索 / RAG（正文素材到位后再加）。
- 不做在线支付、社交、评论等社区功能。
- 卷 2 的 MPC、卡尔曼滤波、LQR 等在 MVP 中只保留课程目录占位，不实现完整交互。

## 2. 用户与使用场景

### 2.1 用户画像
- 单一核心用户：控制理论自学者。
- 数学基础薄弱，对微分方程、拉普拉斯变换、矩阵不熟练。
- 能使用电脑浏览器（Chrome / Edge 最新两个大版本），屏幕宽度 ≥ 1280px。

### 2.2 核心场景
1. 用户进入“二阶系统分析”章节，先看通俗概念解释。
2. 在交互实验室拖动 `ζ`、`ωn` 滑杆，立即看到阶跃响应曲线、极点位置和性能指标变化。
3. 对“为什么欠阻尼会振荡”产生疑问，点击右下角 AI 按钮，在课程页内直接提问。
4. AI 结合当前章节和上下文给出通俗解释；用户继续追问，形成多轮对话。
5. 用户记录笔记，系统保存学习进度，下次打开继续学习。

### 2.3 使用环境
- 本地开发运行：前端 `localhost:5173`，后端 `localhost:8000`。
- 单机使用，SQLite 存储本地数据。
- 大模型调用需要网络；未配置 Key 时自动降级为 Mock 模式。

## 3. MVP 范围

### 3.1 章节范围
只实现一个完整章节：**《控制之美》卷 1 第 5 章“二阶系统的时域响应分析”**。

同时提供：
- 首页课程总览；
- 课程目录树（展示两卷全部章节，未开发章节标记“规划中”）；
- 二阶系统章节内的全部知识点和交互实验。

### 3.2 MVP 学习内容范围
| 编号 | 主题 | 说明 |
| --- | --- | --- |
| 5.1 | 二阶系统的一般形式 | 传递函数与状态空间方程 |
| 5.2 | 二阶系统对初始状态的响应 | 零输入响应，四种阻尼状态 |
| 5.3 | 二阶系统的单位阶跃响应 | 阶跃响应、极点与振荡关系 |
| 5.4 | 二阶系统性能指标分析 | 上升时间、峰值时间、超调量、调节时间 |
| 5.5 | 二阶系统综合实验室 | 参数扫描、多曲线对比、数据导出 |

### 3.3 范围外但保留扩展位
- 一阶系统、稳定性、PID、根轨迹、伯德图等章节：只出现在目录树中，标记“规划中”。
- 章节顺序和标题必须与 `Reference/` 中目录一致。

## 5. 界面与体验要求

1. **视觉风格**：白色背景、大量留白、细边框、轻阴影、低饱和强调色（建议靛蓝或灰蓝），整体简洁优雅。
2. **桌面端优先**：以 1280px–1920px 宽度为设计基准；不做移动端断点。
3. **布局**：
   - 左侧：课程目录树（约 280px，可折叠）。
   - 中间：正文内容（约 720–820px，最大宽度限制，保证可读性）。
   - 右下角：全局 AI 悬浮按钮。
   - AI 面板：宽度约 420px，从右侧滑出。
4. **排版**：正文 15–17px；标题层级清晰；公式居中或随文；代码使用等宽字体。
5. **反馈**：计算加载时显示 loading；AI 流式输出时显示光标；错误使用 toast 或行内提示。
6. **无障碍基础**：滑杆、按钮可键盘操作；文本对比度满足 WCAG AA。

| 类别 | 要求 |

## 7. MVP 验收标准（Definition of Done，概要）

1. 用户能打开首页，看到两卷书目录；进入“二阶系统的时域响应分析”章节。
2. 二阶系统全部知识点可阅读，公式正常渲染，推导区可折叠。
3. 实验室中拖动 `ζ`、`ωn` 滑杆，响应曲线、极点图、指标表在 500ms 内联动更新。
4. 阶跃 / 冲激 / 初始状态三种模式结果正确；临界阻尼、欠阻尼、过阻尼、无阻尼、不稳定五类行为可复现。
5. 性能指标数值与解析公式误差在容差范围内（见 03 文档测试用例）。
6. 右下角 AI 对话在任意页面可用，支持流式输出与多轮历史。
7. 大模型默认 DeepSeek，且可在设置页切换到任意 OpenAI 兼容接口或 Ollama；代码中无写死的供应商。
8. 无 API Key 时 AI 返回 Mock 提示；学习、可视化功能不受影响。
9. 学习进度和笔记在重启后仍然存在。
10. 页面为白色简洁桌面风格，无移动端适配要求。
